# HTML guide builder

The guide is generated by `scripts/render-guide.ps1`, the only writer of `guide.html`
(CLAUDE.md §8.3). Approval is enforced by `state.ps1`, not by you: the renderer's
`start -Step render` refuses unless the approval is valid for exactly the current plan, and
its `complete -Step render` checks it again and verifies the guide's embedded plan hash.

## Steps

1. **Check readiness** (read-only):
   ```
   pwsh -NoProfile -File scripts/state.ps1 ledger-status -RunId <run-id>
   ```
   Continue only if `approval_status` is `approved`, `blockers` is empty, and `plan_sha256`
   equals `accepted_plan_sha256`. Otherwise stop and say why (for example: no approval yet,
   the plan changed since it was approved, an integrity violation). Optionally run the
   `artifact-validator` skill first.
2. **Render**:
   ```
   pwsh -NoProfile -File scripts/render-guide.ps1 -RunId <run-id>
   ```
3. **Read the result** (JSON):
   - `"result": "passed"`: the guide is accepted. Report `runs/<run-id>/guide.html`, its
     `artifact_sha256`, and the approved `plan_sha256`. `workflow_status` is `completed`.
   - `"result": "refused"`: no valid approval of the current plan, the guide was already
     rendered, or an integrity violation. Report `reason`. Nothing was written.
   - `"result": "stale"`: the plan or approval changed during rendering; nothing was
     accepted. The user must decide on the current plan again.
   - `"result": "failed"`: the render attempt failed (`problems` or `reason`); it counts
     against the step's 3 attempts. Run the renderer again only if attempts remain.

## Rules

- Never write, edit, copy, or delete `guide.html` yourself; the PreToolUse hook denies it,
  and a guide no render produced is an integrity violation (`render-output`).
- A plan that changed after approval voids the approval and the guide. Re-rendering needs a
  new decision by the user (`APPROVE PLAN …`), never a workaround.
- The renderer escapes all plan text and emits no scripts or external resources; do not
  post-process its output.
